# Super-Tier Magic

**Minecraft Java 1.20.1 · Forge 47.x · Version 2.3.1**

A magic combat mod featuring seven artifacts, spectacular sky sigils, and powerful forbidden spells.

## Artifacts

- **Flame Talisman & Flame Blade:** burning waves, fiery dashes, and golden meteor rain.
- **Lightning Shard, Lightning Talisman & Thunderclap Blade:** explosive bolts, lightning storms, and terrain-splitting strikes.
- **Sword Intent:** piercing sword waves, homing sword domains, and a colossal celestial sword.
- **Air Talisman:** wind blasts, tornadoes, knockback, and R-key cloud flight.

Find all artifacts in the Combat tab.

## Highlights

- Carry a Flame Talisman or Flame Blade to become immune to fire and lava damage.
- Carry an Air Talisman to gain fall-damage immunity and toggle flight.
- Experience levels reduce casting costs; level 100 removes ultimate health and durability costs by default.
- Enchantments strengthen spells and expand their coverage.
- Artifact kills award XP remotely, preserving Mending. Recipe-based achievements track your progress.

## Setup

Place **super-tier-magic-2.3.1.jar** in your **mods** folder. Keep one version; multiplayer clients and the server must match. No extra mod dependency is required.

Settings are in **config/super-tier-magic-common.toml**. Set **flightCheat = true** under **[air]** to allow R-key flight without an Air Talisman.

Source code is included in **super-tier-magic-source.zip**.
